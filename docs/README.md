# docs/

- `docs/`: current design decisions, test write-ups and `PROGRESS.md`.
- `docs/reviews/`: the review exchanges with the claude.ai review session
  (2026-09-30 onward). They stay here, not in `archive/`, until
  `PROGRESS.md` has been updated with their conclusions.
- `docs/archive/`: superseded handovers and plans.

Files were reorganised in the 2026-10 cleanup. Documents in `archive/` and
`reviews/` are dated records and still use the old flat paths. For example,
`test_B3_real_assemblage.pqi` is now `tests/test_B3_real_assemblage.pqi`, and
the databases are under `databases/`.
